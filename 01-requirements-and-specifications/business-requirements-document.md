# Business Requirements Document (BRD)

## 1. Project Information

**Project Name:** Automation Exercise QA Portfolio  
**Application Under Test:** Automation Exercise  
**Application Type:** E-commerce Web Application  
**Testing Type:** Manual Testing  
**Document Version:** 1.0

---

## 2. Project Objective

The objective of this project is to perform manual testing of an e-commerce web application and verify that its major user flows work as expected.

The testing will focus on identifying functional issues, validating user requirements, and ensuring a reliable user experience.

---

## 3. Business Requirements

### BR-01: User Registration

The application should allow new users to create an account by providing the required registration details.

### BR-02: User Login

The application should allow registered users to log in using their registered email address and password.

### BR-03: Product Browsing

Users should be able to browse available products and view product details.

### BR-04: Product Search

Users should be able to search for products using relevant search terms.

### BR-05: Shopping Cart

Users should be able to add products to the shopping cart, view cart items, update quantities, and remove products.

### BR-06: Checkout

Users should be able to proceed through the checkout process and place an order by providing the required information.

### BR-07: User Logout

Logged-in users should be able to log out of their account successfully.

---

## 4. In-Scope Features

The following features are included in this testing project:

- User Registration
- User Login
- Product Listing
- Product Search
- Product Details
- Shopping Cart
- Cart Quantity
- Product Removal
- Checkout
- Order Placement
- User Logout

---

## 5. Out of Scope

The following areas are outside the scope of this project:

- Source code testing
- Server-side infrastructure testing
- Production monitoring
- Payment gateway internal processing
- Performance/load testing
- Security penetration testing
- Mobile application testing

---

## 6. Business Goal

The main goal is to verify that the core e-commerce functionality works correctly from a user's perspective and to identify defects before the application is considered ready for use.

---

## 7. Success Criteria

The testing will be considered successful when:

- Major in-scope user flows have been tested.
- Critical and high-priority defects are identified and reported.
- Test cases have been executed and results documented.
- Requirements have appropriate test coverage.
- The final test results are documented in a test summary.
